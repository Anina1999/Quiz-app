# ADR-0015 — Децата нямат пряк достъп до таблици

- **Статус:** прието
- **Дата:** 2026-09-06

## Контекст

Anon ключът се вгражда в JavaScript файла и е видим за всеки посетител. Това е
по замисъл — сам по себе си той не дава достъп. Но ако ролите имат права върху
таблиците, „сам по себе си“ спира да важи.

## Решение

- Ролята `anon` е **лишена от всякакви права**. Има готова заявка
  `supabase/tools/fix-anon-grants.sql`, която маха останали права, и
  `diagnose-anon.sql`, която показва кой какви е дал.
- Детето влиза с **анонимна сесия** на Supabase и работи **само през SQL
  функции** (`class_preview`, `claim_student`, `student_quizzes`,
  `start_attempt`, `submit_answer`, `finish_attempt`, `student_progress`).
- Учителят има права само върху собствените си редове, наложено с RLS.
- Всички функции са със `search_path = ''`.

## Последици

- Дете не може да прочете чужди резултати, верни отговори или да си направи
  учителски профил. Точно това проверява `npm run test:smoke`.
- Всяка нова възможност за ученика изисква нова SQL функция, не заявка от
  браузъра. По-бавно за писане, но границата остава на едно място.
