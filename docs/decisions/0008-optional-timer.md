# ADR-0008 — Таймерът е избор на учителя

- **Статус:** прието
- **Дата:** 2026-09-06

## Контекст

Диктовка и задача за разсъждение не търпят една и съща мярка за време. За
по-бавно четящо дете часовникът е източник на стрес, а не на дисциплина.

## Решение

`quizzes.time_per_question` допуска `NULL`. `NULL` означава тест **без
ограничение във времето**.

Тест без таймер **изобщо не показва часовник** на екрана — празното поле само по
себе си притеснява децата ([src/pages/Play.jsx](../../src/pages/Play.jsx)).

## Последици

- Учителят решава според задачата, не според приложението.
- Логиката в `useQuizGame` има два пътя (с и без таймер). Цената е малка.
- Основа за SEN режима, където времето се удължава за конкретно дете —
  [ADR-0021](0021-sen-profile-per-student.md).
