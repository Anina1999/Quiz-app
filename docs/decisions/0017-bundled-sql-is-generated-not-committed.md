# ADR-0017 — Слепеният SQL се генерира, не се пази в Git

- **Статус:** прието
- **Дата:** 2026-09-06

## Контекст

Не всеки има свързан Supabase CLI. За такъв случай е удобно да има един файл,
който се поставя наведнъж в SQL Editor. Но копие в хранилището рано или късно
изостава от миграциите — и точно това веднъж вече доведе до пропусната промяна
при пускане.

## Решение

`npm run db:bundle` слепва миграциите в `supabase/dist/full-schema.sql`. Папката
е в `.gitignore`. Източникът на истината е **само** `supabase/migrations/`.

## Последици

- Невъзможно е да се пусне остарял слепен файл — той се произвежда в момента.
- Който иска файла, пуска една команда.
- Виж [error-log](../error-log.md) — правилото в `.gitignore` трябва да е
  `/dist/` с наклонена черта отпред, иначе хваща и `supabase/dist/`.
