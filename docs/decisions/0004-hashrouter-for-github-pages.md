# ADR-0004 — HashRouter, не BrowserRouter

- **Статус:** прието
- **Дата:** 2026-09-06

## Контекст

Приложението се хоства на GitHub Pages — статичен хостинг без сървър, който да
пренасочва дълбоките адреси към `index.html`. С `BrowserRouter` директното
отваряне на `/student/quizzes` или обновяването на страницата дава 404.

## Решение

`HashRouter` в [src/main.jsx](../../src/main.jsx). Адресите изглеждат като
`.../Quiz-app/#/student/quizzes`.

Съответно `vite.config.js` задава базов път `/Quiz-app/`, защото Pages сервира
проекта в подпапка.

## Последици

- Всеки адрес работи при директно отваряне и при обновяване.
- Диезът в адреса е малко по-грозен. За приложение, в което се влиза с код от
  дъската, това няма значение.
- При смяна на хостинга (Netlify, Vercel, собствен домейн) билдът се пуска с
  променлива на средата `DEPLOY_BASE=/`.
