# Дневник на сесиите

Какво е свършено в коя сесия. Най-новото е най-отгоре.

**Защо съществува.** Всяка нова сесия започва без памет за предишната. Този файл
е връзката: какво е направено, докъде е стигнато, какво следва.

**Какво влиза в един запис:** какво е свършено · какви решения са взети · какво
е следващото · какво е останало недовършено и защо.

- Лицензът сменен от MIT на **„Всички права запазени“**, двуезично.
  [ADR-0025](decisions/0025-all-rights-reserved.md); README обновен.

**Решения**

- [ADR-0025](decisions/0025-all-rights-reserved.md) — всички права запазени.
  Отхвърлени: PolyForm Noncommercial, CC BY-NC-ND, затваряне на хранилището.
- Записано изрично, че MIT е неотменим за вече публикуваните версии. При 0
  форка и 0 звезди смяната е чиста на практика.

**Проверено, не предположено**

- `.env.local` е игнориран от Git и **никога** не е влизал в историята.
- В проекта няма `service_role` ключ.
- Anon ключът е публичен по замисъл — защитата идва от RLS
  ([ADR-0015](decisions/0015-anon-role-has-no-privileges.md)), не от тайната му.

**Следващо**

Планът от [plan.md](plan.md) все още чака одобрение. Фаза 1 започва от M2

**Свършено**

  останалото в `docs/`.

- [glossary.md](glossary.md), [open-questions.md](open-questions.md),
  [plan.md](plan.md), [phases.md](phases.md).

**Решения**

- Документацията отива в `docs/`, а не в корена. `CLAUDE.md` остава в корена,
  защото Claude Code го чете оттам.
- Едно решение = един файл; [decisions.md](decisions.md) е само указател.
- Решенията не се изтриват и не се пренаписват — отпадналото получава статус
  „заменено“ и сочи към новото.
- Четири решения се обявяват за непипаеми без изричен разговор:
  [0001](decisions/0001-no-child-personal-data.md),
  [0002](decisions/0002-grading-in-the-database.md),
  [0005](decisions/0005-no-third-party-requests.md),
  [0015](decisions/0015-anon-role-has-no-privileges.md).

**Недовършено**

- Планът **чака одобрение.** Нито един ред приложен код не е променян.
- Осем отворени въпроса, два от които блокиращи (Q-01 български глас, Q-02
  реалните устройства).

**Следващо**

Одобрение на [plan.md](plan.md), после Фаза 1 — започвайки от **M2 (палитра и
дизайн-токени)**, защото маскотът, значките и оформлението за дъска взимат
цветовете си от нея.

## Сесия 1 — 2026-09-06 · Одит на заварено състояние

**Свършено**

Пълен преглед на структурата, тех стека, зависимостите, схемата на базата, RLS
политиките, CI и стиловете. Нищо не е променяно.

**Какво показа одитът**

Приложението не е незавършено — работят класове, ученици с псевдоними, редактор
на тестове, режим на час, банка с въпроси, подсказки и обяснения, напредък,
протокол за печат, RLS, smoke тест от 130 проверки и автоматичен деплой.
`npm run build` минава чисто.

Три неща са направени по-добре от очакваното и трябва да се подчертаят пред
училище: липсата на лични данни на деца, оценяването в базата и нивото на
достъпност (skip link, видим фокус, `aria-live`, ✓/✗ освен цвят, цели 56px,
`prefers-reduced-motion`).

**Намерени проблеми**

| Тежест | Проблем |
|---|---|
| 🔴 | **Снимката към въпрос е мъртва функция.** Колоната и показването съществуват, поле в редактора — не. |
| 🟠 | Няма геймификация (значки, серии, награда). |
| 🟠 | Няма SEN режим — `speechSynthesis` не се среща никъде в кода. |
| 🟠 | Напредъкът е само по предмет, не по тема. |
| 🟠 | Няма офлайн поддръжка — нито service worker, нито manifest. |
| 🟡 | Дизайнът е корпоративен; нула илюстрации, `public/` съдържа само два mp3. |
| 🟡 | Един-единствен breakpoint (620px); интерактивната дъска не е покрита. |
| 🟡 | Бъндъл 513 KB / 149 KB gzip в едно парче — учителският код се сваля и на ученическия таблет. |
| 🟡 | Няма favicon, `theme-color`, ESLint; CI прави само билд. |
| 🟢 | Сигурност — критичен проблем не е намерен. `.env.local` е коректно игнориран, `anon` е лишен от права, публичният ключ е публичен по замисъл. Единствена бележка: `image_url` приема произволен чужд домейн. |

**Отбелязано**

Higgsfield MCP не беше свързан в тази сесия.

**Следващо**

Изготвяне на приоритизиран план (Must / Should / Nice) за одобрение.
